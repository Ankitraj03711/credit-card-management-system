# Credit Card Management System

A full-stack web application for managing customers, credit cards, card applications, transactions, payments, and reports.

The system provides separate functionality for Admin and Customer users. The frontend is developed using React.js with Vite, while the backend is developed using Spring Boot and MySQL.

## Features

### Admin
- Admin login and authentication
- Customer management
- Credit card management
- Card type management
- Credit card application management
- Transaction management
- Payment management
- Dashboard with system statistics
- Reports and analytics
- Activate, block, unblock and close cards

### Customer
- Customer registration and login
- View and update profile
- Apply for credit cards
- View credit cards
- View transactions
- Make payments
- View payment history
- View card details and status
